# Five-minute demonstration script

This is a planned presentation budget, not a measured completion-time benchmark. Complete [the runbook](DEMO_RUNBOOK.md) first. M10 release is currently blocked; disclose that status during any review demonstration. Do not edit out failures and describe them as live success.

| Time budget | Screen and action | What to establish |
|---|---|---|
| 0:00–0:35 | USER creates: “Khách hàng ABC có 17 SIM IoT tại KCN Amata bị mất kết nối từ khoảng 8 giờ sáng.” | Synthetic input, saved request and visible AI progress |
| 0:35–1:30 | MANAGER opens analysis, requests recommendation and inspects evidence | Actual extraction, real SOP-IOT-04 source, actual similarity/SLA/candidate results; no assignment before approval |
| 1:30–2:15 | MANAGER reviews and accepts or modifies an eligible assignee | Original AI suggestion and final human decision remain separate |
| 2:15–3:35 | Sign in as the actual approved STAFF; start work, request a grounded checklist, explicitly save/complete it | AI proposes; staff acts and records verification |
| 3:35–4:25 | STAFF resolves with root cause/resolution/verification; USER confirms | Resolution summary is advisory; owner controls closure |
| 4:25–5:00 | MANAGER opens analytics and request history | Stored workflow outcomes and distinctly labeled synthetic evaluation evidence |

If inference takes longer, acknowledge the live wait and extend the presentation or show a clearly labeled previously completed synthetic request. Never substitute recorded AI output as the result of the current request. For an error, show its code/state and the manual path; retry only after fixing availability. Do not promise a particular recommended staff member, similarity count, or model label.
