# V1.1 authenticated product and login surfaces

Mode: Operate. Scope: `/login`, `/`, and every authenticated USER, STAFF, and MANAGER route in `apps/web`.

Audience: Vietnamese office users coordinating telecom service requests. Their job is to understand attention, authority, SLA, and next action in seconds. The primary task is the valid role-specific workflow action. Proof is real request, health, analytics, evidence, and state data already exposed by V1 APIs. Constraints: Vietnamese-first, existing icon asset and system type, frontend-only, fixed roles/contracts, no dark mode, complete 360–1920 px behavior.

## Direction contract

THESIS: MobiFlow is an enterprise operations relay: every screen hands a request, signal, or decision cleanly to the next accountable human. It refuses the category default of a marketing hero followed by unrelated dashboard cards.

OWN-WORLD: A cool white and slate operations field is organized by precise blue routing lines, compact signal badges, dense but calm tables, and a sparse red attention mark. Corners are 9–12 px, rules do more work than shadow, Lucide icons share one stroke language, and the existing blue mark anchors identity.

STORY: A user immediately sees what requires attention, the current operational truth, and the one valid next action. AI appears as a bounded advisory signal with sources and state; decision ownership is visually returned to the authorized human.

FIRST VIEWPORT: Authenticated desktop opens with a 248 px role-aware rail, a 64 px context bar, and a controlled work canvas. A compact page header and one row of four scoped KPIs occupy the upper third; the live work list begins without scrolling. Login instead uses a restrained blue network field beside a 440 px sign-in card. The signature interaction is the mobile navigation relay: the active path moves into a modal drawer that contains focus, closes on navigation/Escape, and returns focus to its trigger.

FORM: Brief-pinned “Modern Vietnamese Telecom Enterprise UI,” selected as canon over seven grounded directions after seed `b9eda09c`. The brief’s operational clarity and approved blue asset outrank foreign material systems; the build keeps the challengers’ discipline through strict density, one continuous information topology, deliberate state transitions, and responsive reduction without spectacle.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Unresolved decisions: none. The task explicitly fixes the brand posture, content language, information hierarchy, responsive targets, and behavioral boundary.
